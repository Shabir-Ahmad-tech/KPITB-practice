# KPITB Python Lab - Week 01 🐍

Welcome to Week 01 of your Python journey! This week covers the fundamental building blocks of Python programming.

## Curriculum Overview

This directory contains interactive Python scripts designed to teach you the core concepts through gaming-themed examples.

### 📜 Files in this Module:

| File Name | Topic | Description |
| :--- | :--- | :--- |
| `01_variables_and_types.py` | Variables & Data Types | Storing data (Points, Names), Integers, Floats, Strings, Booleans. |
| `02_lists.py` | Lists | Managing collections (Squads, Items). Adding, removing, slicing. |
| `03_tuples.py` | Tuples | Immutable data (Coordinates, IDs). Understanding fixed collections. |
| `04_sets.py` | Sets | Unique collections (Inventory without duplicates). Union, intersection. |
| `05_dictionaries.py` | Dictionaries | Key-Value pairs (Player Profiles). Storing structured data. |
| `06_conditionals.py` | Conditionals `if/else` | Making decisions (Level checks, unlocking doors). |
| `07_for_loops.py` | For Loops | Repeating actions (Iterating through squads, ranges). |
| `08_loop_control.py` | Loop Control | Break, Continue, Pass. hacking the loop flow. |
| `09_while_loops.py` | While Loops | Loops based on conditions (Health bars, Game loops). |
| `10_functions.py` | Functions | creating reusable skills (Abilities, Heals). |

## 🚀 How to Run

1.  Make sure you have Python installed.
2.  Open your terminal or command prompt.
3.  Navigate to this folder: `cd "KPITB lab/Week 01"`
4.  Run any file using the `python` command:
    ```resh
    python 01_variables_and_types.py
    ```

## 🛠️ Tips for Success

-   **Read the Comments**: Every file is heavily commented to explain *why* we are doing something, not just *how*.
-   **Experiment**: Try changing the values (e.g., change `health = 100` to `health = 500`) and see what happens!
-   **Practice**: Try to write your own small scripts based on these examples.

Good luck, and Happy Coding! 🎮
